COMPONENTES E FERRAMENTAS

5. Componentes e Suprimentos

Lista de materiais utilizados para a construção do projeto:

  • Arduino Uno – Responsável pelo controle lógico do sistema.
  • Sensor Ultrassônico – Realiza a medição de distância.
  • Protoboard e Jumpers – Utilizados para a montagem e conexões do circuito.
  • LEDs – Para sinalização visual dos estados.

6. Aplicativos e Plataformas

Softwares e ferramentas digitais empregados:

  • Arduino IDE – Versão 2.3.2 (Desenvolvimento do código).
  • Visual Studio Code – Versão 1.93 (Edição do site e documentação).
  • GitHub – Hospedagem do código fonte e do site (Pages).
