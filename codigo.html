8. Exemplo do Código Arduino

Abaixo está um trecho ilustrativo da lógica utilizada. O estilo visual abaixo facilita a leitura como em uma IDE.


// Exemplo simples de código Arduino
int led = 13;

void setup() {
  pinMode(led, OUTPUT);
}

void loop() {
  digitalWrite(led, HIGH);
  delay(1000);
  digitalWrite(led, LOW);
  delay(1000);
}
