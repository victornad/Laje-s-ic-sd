7. Montando o Circuito

Siga a ordem abaixo para garantir o funcionamento correto do hardware:

  1. Montagem Física: Monte o circuito na protoboard conforme o esquema.
  2. Conexão: Conecte o Arduino ao computador via cabo USB e carregue o código utilizando a IDE.
  3. Testes: Execute o teste do sistema verificando se o sensor responde aos estímulos e se os LEDs acendem.
  4. Ajustes Finais: Ajuste os valores de sensibilidade e tempos de resposta no código conforme a necessidade prática.
